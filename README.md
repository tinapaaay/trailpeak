# TrailPeak

Find joiner hikes and group climbs across the Philippines (Batulao, Mariglem, Pulag and more), check difficulty, meetup schedule, pick-up points and the event fee, and reserve a slot with a down payment.

**Live prototype:** https://tinapaaay.github.io/trailpeak/

> This is a prototype. Accounts (email code), trips and bookings are real and stored in Supabase; joiners pay organizers directly and organizers record DP receipt. TrailPeak does not move money or verify wallet transfers. ID checks and text messages are still simulated.

## Why

Joiner hikes in the Philippines are organized in Facebook groups: long hand-typed posts with dates, fees, inclusions and pick-up points, and booking happens one DM at a time. TrailPeak turns those posts into trips people can search, compare and reserve, while organizers keep posting in their groups with a link back.

## Try it

- **Joiners:** search by mountain, date, group size and pick-up point, open a trip, choose a date, and reserve. Sign in with your email and the code it sends you.
- **Organizers:** open **Post a trip**, then open the dashboard to see real bookings on your trips. (With an empty `config.js`, the offline demo has a sample organizer account and the test code `123456`.)

## Pages

- `index.html`: search (place, this weekend / next weekend / a date, group size, pick-up) and trip cards
- `trip.html`: trip page for any trip, e.g. `trip.html#mt-pulag-akiki`, with who's going, reviews and an ask-the-organizer message
- `org.html`: organizer profile, e.g. `org.html#batangas-trail-co`
- `signin.html`: mock sign-in for joiners (Facebook, mobile code, email)
- `reserve.html`: reserve real slots with DP pending, then pay the organizer directly
- `demo.html`: isolated in-memory booking simulation, with no account/API access
- `mytrips.html`: a joiner's bookings, with move date and cancel, and a review once the trip date has passed
- `organizer-signup.html`: mock organizer sign-up (account, ID check, business, payout)
- `organize.html`: organizer form to post a trip, with live preview, Facebook text and a share image; `organize.html?edit=<trip id>` edits a trip you published
- `dashboard.html`: organizer dashboard with bookings, joiner list, payouts, and add/close/cancel dates (past dates show as Done)
- `privacy.html`, `terms.html`: privacy policy and terms of service (needed for Google sign-in)
- `styles.css`: shared tokens and components used by every page
- `trips.js`: details for every trip (shared by search and trip pages)
- `cards.js`: shared trip card code
- `auth.js`: mock accounts and bookings kept in the browser, and the header account menu
- `build.py`: makes a self-contained copy in `site/` (downloads photos locally) for hosts that block outside images

## Backend

A light backend on Supabase gives real accounts (email code), shared trips, live slots and bookings that organizers see; direct DP receipt records remain separate from reservation status; TrailPeak does not process payments. ID checks and text messages remain simulated. `api.js` talks to Supabase and keeps the pages on the same data shapes as before. Setup steps are in [supabase/SETUP.md](supabase/SETUP.md): `schema.sql` (tables and privacy rules), `seed.sql` (sample trips, generated by `node supabase/make-seed.js`) and `config.js` (project URL and public key). Without them, the site runs in offline demo mode.

## Run it locally

No build step. Serve the folder with any static server, for example:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.
